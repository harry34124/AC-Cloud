# 美术开发素材包

继续开发运行逻辑，直接使用本仓库。需要改人物组件、武器、车辆、道具或绑定时，再下载独立的 **[美术开发素材包](https://github.com/harry34124/AC-Cloud/releases/download/v0.1.0/AC-Cloud-v0.1.1-art-sources.zip)**（[SHA256校验文件](https://github.com/harry34124/AC-Cloud/releases/download/v0.1.0/AC-Cloud-v0.1.1-art-sources.zip.sha256)）。附件放在原v0.1.0发布页，素材整理版本为v0.1.1，不代表Windows程序更新；旧版程序和源码ZIP内没有这一素材包。

本次打包约327 MiB，包含去重后的61份PSD、15份CMO、2张形象参考，以及35项动作/共用状态/表情的素材对应记录。SHA256为 `cf1d2a7c440e112baedcb4255d5b97866ee6a583c045fa006b2d31fe2005de5e`。

## 包内内容

- `PSD/人物、武器、摩托车、道具/`：分类保存的分层源文件；重复字节只保留一份，原路径保存在目录记录中。
- `绑定工程/`：已保存且能确认来源的CMO编辑参考，按用途命名。
- `形象参考/`：已选用的多视角和造型对照。
- `动作素材索引.md`：按动作编号查找对应PSD和绑定参考。
- `catalog.json`：源版本、来源路径、认可范围、文件尺寸、PSD图层计数和SHA256。
- `SHA256SUMS.txt`、`NOTICE.md`：校验与原有版权说明。

不打入历史冻结包的层层嵌套、未采用候选、开发工具、个人设置或运行环境。分类目录里的原始输入和补充道具仍有价值，但不因被打包就变为已通过动作素材；具体状态看目录记录。

## 如何继续制作

1. 在动作素材索引中定位相关PSD，用图像编辑器打开独立副本。需要改绑定时，再使用对应CMO编辑参考。
2. 同时检查源码 `app/desktop/daily.json` 对应动作的实际配置。模型、组件和动作模块的虚拟URL通过 `app/release-manifest.json` 映射到 `app/assets/` 的文件。
3. 保留同一套曲线、表情、台词、材质交接与收尾。新导出不能只替换MOC而遗漏其他动作依赖；需要维护模型内的贴图和其他相对引用。
4. 有意修改运行资源后，更新映射和校验，再执行检查：

   ```powershell
   python scripts/update_manifest.py
   npm run check:all
   ```

CMO并不包含所有最终桌面行为。部分动作是共用模型或PSD/PNG组件加代码变形；缺少独立CMO时不使用旧候选冒充。保存的CMO是可编辑生产参考，运行导出还经过后续修复与优化，必须对照当前效果。SI03保留较大的原始编辑工程，运行包继续采用精简导出。A10的现有“需要调整”标记保持。

## 维护与重新打包

本仓库只提交打包工具和选材配置，不把大体积PSD加入Git历史。打包工具使用Python标准库；无需安装图像处理依赖：

```powershell
python scripts/build_art_sources.py --source-root "D:/制作工程/CloudDesktopPet" --output "D:/打包输出/art-sources"
```

素材输入：正式PSD分类目录，加上当前运行动作及其依赖在制作登记中明确列出的PSD；原生工程和形象参考由 `docs/art-source-selection.json` 精确选取。版本不一致、文件缺失、重名冲突会停止打包。内容相同按SHA256去重，不按名字合并不同版本。

脚本不修改输入，不覆盖已有同名ZIP。输出ZIP、外部SHA256文件和打包摘要。打包后回读整个ZIP、核对CRC和每个文件hash；PSD检查仅包含头部/图层计数，CMO检查仅包含签名，不声称重新完成了全部编辑器和视觉验收。

ZIP和外部SHA256文件作为GitHub Release附件提供，首页链接到实际附件。素材包与源码版本分别记录；后续只修改代码时，不必重复发布同一份美术附件。使用范围沿用[版权说明](../NOTICE.md)，不因为提供开发文件而扩大第三方角色或素材授权。
